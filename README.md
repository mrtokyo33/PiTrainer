# Pi Trainer

A simple web app to train and track how many digits of π you can memorize

## Features

* User registration & login
* Track how many digits of π you can recall
* Save your progress
* Simple leaderboard (future)

## Tech Stack

* Backend: Go (Gin)
* Database: SQLite / PostgreSQL
* Frontend: [deciding]
